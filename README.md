# rock-paper-scissors

## Description
This game was inspired by the original Rock Paper Scissors game, which was believed to have originated in China, around 206 BC (Before Christ) to 220 AD (Anno Domini). The original game initially had symbols of animals such as the frog, snake and the centipede to represent the user's choice. The game was later imported to Japan where the iconic symbols rock, paper and scissors were created.

My version of Rock Paper Scissors allows a user to play against a computer. At the start of the game a user must pick one of three symbols: rock, paper or scissors. The computer randomly picks a value from the same symbols and then displays this value to the user. If the user has picked the same symbol as the computer this results in a draw, therefore the round will restart to decide a winner. If the user has either won or lost the round, they will be able to restart or exit the game.

## Requirements
This game was built using Unity 6.5 (6000.5.6f1) on a Windows (64-bit) platform.
